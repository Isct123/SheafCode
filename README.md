# SheafCode

Code archive for **SheafCode: Recovering Pollution Information During Sensor Outages**.

Download [SheafCode_All_Code_No_Comments.zip](SheafCode_All_Code_No_Comments.zip) for the source package.

The archive contains 509 source files covering the research implementation, experiments, verification, figure/document tools and launchers. It includes historical and exploratory scripts alongside the code used for the final manuscript. Source comments and Python docstrings were removed from the packaged copies; third-party attribution and provenance are retained. The original working files were unchanged.

Monitoring datasets, trained models, result files, installed dependencies and executable runtimes are not included. The archive README and MANIFEST.json describe its contents, dependencies and validation limits.
